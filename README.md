# Prompt Engineering Journal

A learning journal for prompt engineering, built by practice. I write a prompt,
get it reviewed, rewrite it, and extract one lesson from each round.

## Review process

1. **Score** - the prompt is rated from 1 to 10.
2. **Strengths** - what already works is named.
3. **Issues as hints** - problems are pointed out as hints, not fixes.
4. **I rewrite** - I improve the prompt myself based on the hints.
5. **Claude's version** - a reference version is shown for comparison.
6. **Lesson** - one principle is extracted and recorded.

## Structure

- `lessons/` - one file per principle learned.
- `before-after/` - the full review record for each prompt.
- `templates/` - reusable, tested prompts.
